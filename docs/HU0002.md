## 1. Especificação da História de Usuário

- **Como:** Usuário com cadastro
- **Quero:** Entrar no sistema
- **Para:** Acessar as funcionalidades exclusivos do sistema

<br>

## 2. Cenários

### 2.1 Entrar no Sistema

- **DADO** Que sou um usuário com cadastro
- **QUANDO** Preencho o formulário de login com seu nome de usuário e senha
- **E** Clico no botão de entrar
- **ENTÃO** O sistema valida as credenciais e envia o usuário para a página inicial do sistema

<br>

## 3. Critérios de Aceitação

- [ ] **3.1.** O usuário deve conseguir entrar no sistema e permanecer logado com sua conta.

<br>
