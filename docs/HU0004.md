## 1. Especificação da História de Usuário

- **Como:** Usuário autenticado
- **Quero:** Acessar a página inicial
- **Para:** Publicar postagens no sistema

<br>

## 2. Cenários

### 2.1 Visualizar

- **DADO** Que sou um usuário autenticado
- **QUANDO** Acesso a página principal
- **E** Clico no botão "Publicar Postagem"
- **E** Preencho o formulário com título e descrição
- **E** Clico no botão "Publicar"
- **ENTÃO** O sistema valida os dados, fecha o modal e atualiza a listagem de postagens

<br>
